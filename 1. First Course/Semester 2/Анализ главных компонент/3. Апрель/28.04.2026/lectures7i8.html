📐 Лекция 7: Метрическая классификация методов

Цель: Построение единой системы выбора метода снижения размерности в зависимости от типа данных и цели анализа.

1.1. Финальный словарь терминов (русский / english)

PCA (Principal Component Analysis) — анализ главных компонент, линейное сжатие по дисперсии.
FA (Factor Analysis) — факторный анализ, моделирование латентных факторов.
CA (Correspondence Analysis) — анализ соответствий для контингентных таблиц.
MCA (Multiple Correspondence Analysis) — множественный анализ соответствий (категориальные данные).
MDS (Multidimensional Scaling) — многомерное шкалирование по матрице расстояний.
KPCA (Kernel Principal Component Analysis) — нелинейный PCA через ядро.
Isomap (Isometric Mapping) — нелинейное сжатие через геодезические расстояния.
Λ (loadings) — факторные нагрузки, корреляция переменной с фактором.
h² (communality) — доля дисперсии, объяснённая общими факторами.

1.3. Единая математическая основа — SVD

\[ \text{PCA: } \Sigma = U\Lambda U^T,\quad \text{CA: } D_r^{-1/2}(P-rc^T)D_c^{-1/2}=U\Lambda V^T \] \[ \text{MDS: } B=-\frac{1}{2}H D^2 H,\quad B = U\Lambda U^T,\quad \text{KPCA: } K = \Phi(X)\Phi(X)^T = U\Lambda U^T \]

Все методы сводятся к сингулярному разложению (SVD) некоторой матрицы сходства/расстояния/ковариации.

1.4. Алгоритм выбора метода (choose_method())

def choose_method(data_type, nonlinearity=False):
    """Автоматический выбор метода снижения размерности."""
    if data_type == "numeric": 
        return "PCA/FA (линейное сжатие)"
    elif data_type == "categorical": 
        return "MCA (one-hot + CA)"
    elif data_type == "contingency": 
        return "CA (χ²-расстояние)"
    elif data_type == "distances": 
        return "MDS (классическое или неметрическое)"
    elif nonlinearity:
        return "KernelPCA или Isomap (нелинейные manifold)"
    else:
        return "Попробуйте t-SNE или UMAP"

Пример вызова: choose_method("categorical") → MCA.

2.3. Промышленный pipeline синтеза

# Универсальный pipeline снижения размерности
from sklearn.pipeline import Pipeline
def universal_pipeline(data_type, X, **params):
    if data_type == "categorical":
        from prince import MCA
        return Pipeline([('dummy', OneHotEncoder()), ('mca', MCA(n_components=2))])
    elif data_type == "numeric":
        from sklearn.decomposition import PCA
        return Pipeline([('scale', StandardScaler()), ('pca', PCA(n_components=0.95))])
    elif data_type == "distances":
        from sklearn.manifold import MDS
        return MDS(dissimilarity='precomputed')
    else:
        return KernelPCA(kernel='rbf')
