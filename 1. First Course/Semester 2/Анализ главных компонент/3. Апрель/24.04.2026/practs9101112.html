📐 Практика 9: Correspondence Analysis (CA)

Цель: анализ контингентных таблиц (частот/процентов) для выявления связей между категориальными переменными. Применяется в маркетинге, социологии, биоинформатике.

\[ \text{Матрица } \mathbf{P} = \frac{N_{ij}}{\sum N_{ij}}, \quad \text{Профили строк: } \frac{p_{ij}}{p_{i+}}, \quad \text{Расстояние } \chi^2: \quad d^2(i,i') = \sum_j \frac{(p_{ij}/p_{i+} - p_{i'j}/p_{i'+})^2}{p_{+j}} \]

SVD: \(\mathbf{D}_r^{-1/2}(\mathbf{P} - \mathbf{r}\mathbf{c}^T)\mathbf{D}_c^{-1/2} = \mathbf{U}\mathbf{\Lambda}\mathbf{V}^T\) → главные координаты.

Инструмент: библиотека prince.CA() (документация) или sklearn (самостоятельно).

📌 Пример Python кода (города × типы преступлений)

import pandas as pd
import prince
import matplotlib.pyplot as plt

# Данные: контингентная таблица
data = pd.DataFrame({
    'Угон': [80, 20, 50],
    'Кража': [30, 70, 40],
    'Мошенничество': [20, 10, 60]
}, index=['Москва', 'Питер', 'Казань'])

ca = prince.CA(n_components=2)
ca = ca.fit(data)
# Координаты строк и столбцов
row_coords = ca.row_coordinates(data)
col_coords = ca.column_coordinates(data)

# Biplot
plt.figure(figsize=(10,8))
plt.scatter(row_coords[0], row_coords[1], c='blue', s=100, label='Города')
plt.scatter(col_coords[0], col_coords[1], c='red', marker='^', s=100, label='Преступления')
for city in row_coords.index:
    plt.annotate(city, (row_coords.loc[city,0], row_coords.loc[city,1]))
for crime in col_coords.index:
    plt.annotate(crime, (col_coords.loc[crime,0], col_coords.loc[crime,1]))
plt.title('CA Biplot: города и преступления')
plt.xlabel('Измерение 1')
plt.ylabel('Измерение 2')
plt.legend()
plt.grid(alpha=0.3)
plt.show()

Интерпретация: близость точек на карте означает схожесть профилей (ассоциацию).

🔢 Практика 10: Multiple Correspondence Analysis (MCA)

Цель: анализ нескольких категориальных переменных (опросы, анкеты). MCA — это CA на индикаторной (dummy) матрице или на Burt-матрице.

\[ \text{Индикаторная матрица } Z \ (n \times q), \quad \text{Burt-матрица } B = Z^T Z \]

Инерция = сумма собственных значений. Категории рядом → ассоциация.

Инструмент: prince.MCA() (документация).

import prince
import pandas as pd
from sklearn.preprocessing import OneHotEncoder

# Данные опроса
df = pd.DataFrame({
    'Пол': ['М','М','Ж','Ж','М'],
    'Возраст': ['молодой','средний','средний','пожилой','молодой'],
    'Доход': ['низкий','средний','высокий','средний','низкий'],
    'Предпочтение': ['A','B','A','C','B']
})
mca = prince.MCA(n_components=2, one_hot=True)
mca = mca.fit(df)
# Координаты индивидов и категорий
ind_coords = mca.transform(df)
cat_coords = mca.column_coordinates(df)
print("Инерция:", mca.eigenvalues_summary_)

📏 Практика 11: Multidimensional Scaling (MDS)

Цель: визуализация объектов на основе матрицы попарных расстояний (метрическое или неметрическое шкалирование).

\[ \text{Классическое MDS: } B = -\frac{1}{2} H D^2 H, \quad H = I - \frac{1}{n} 11^T \]

Собственные векторы \(B\) → координаты. Неметрическое MDS минимизирует стресс: \(\sqrt{\frac{\sum (d_{ij} - \hat{d}_{ij})^2}{\sum d_{ij}^2}}\).

from sklearn.manifold import MDS
import numpy as np

# Матрица расстояний (евклидовых или любых)
dist_matrix = np.array([[0, 1, 2], [1, 0, 1.5], [2, 1.5, 0]])
mds = MDS(n_components=2, dissimilarity='precomputed', random_state=42)
coords = mds.fit_transform(dist_matrix)
print(coords)

Связь с предыдущим: MDS на евклидовых расстояниях эквивалентен PCA. Неевклидовы метрики — уникальное преимущество.

🌀 Практика 12: Kernel PCA + Isomap

Цель: нелинейное снижение размерности для сложных структур (например, «швейцарский руль», полумесяц).

Kernel PCA
\[ \mathbf{K}_{ij} = \langle \phi(x_i), \phi(x_j) \rangle \]

Центрирование ядра, PCA в пространстве признаков. Ядра: RBF, полиномиальное.

from sklearn.decomposition import KernelPCA
kpca = KernelPCA(n_components=2, kernel='rbf', gamma=15)
X_kpca = kpca.fit_transform(X_swissroll)
Isomap
\[ \text{Геодезические расстояния → классическое MDS} \]

Строится граф k‑ближайших соседей, расстояния кратчайших путей.

from sklearn.manifold import Isomap
iso = Isomap(n_components=2, n_neighbors=5)
X_iso = iso.fit_transform(X_swissroll)

Сравнение с предыдущими: Kernel PCA и Isomap превосходят линейный PCA на нелинейных многообразиях.

📚 Тезаурус и полезные ссылки

  • CA – Correspondence Analysis, анализ соответствий.
  • MCA – Multiple Correspondence Analysis, множественный анализ соответствий.
  • MDS – Multidimensional Scaling, многомерное шкалирование.
  • Burt-матрица – матрица попарных кросс-таблиц категорий.
  • Kernel PCA – ядерный метод главных компонент.
  • Isomap – изометрическое отображение (геодезические расстояния).
