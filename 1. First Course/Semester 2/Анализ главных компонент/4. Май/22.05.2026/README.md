# 1. Установка зависимостей

Необходимо из исходной папки открыть консоль (командная строка) и запустить установку зависимостей, как показано ниже.

```
pip install -r requirements.txt
```

# 2. Запуск приложения

Остаемся в командной строке. После установки зависимостей необходимо запустить приложения. Конфигурация ```python``` не позволяет запустить ```streamlit``` в чистом виде, поэтому используется ```CLI streamlit```.

```
streamlit run app.py
```

Приложение откроется в браузере. Чтобы прикротить работу приложени в консоли необходимо нажать клавиши ```Ctrl-C```.
